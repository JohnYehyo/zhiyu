# 图片和视频接入验证

验证日期：2026-10-13。使用本地运行时配置连接真实 Cloudflare R2 `blog` 桶；不显示密钥，不改动现有媒体或文章。

## 已有实现

正式文章编辑器支持图片、视频与图片封面上传，以及选择已有素材。流程为：服务端登记待上传素材并签名 → 浏览器 File 直传 R2 → 服务端 HEAD 校验类型和大小 → 登记 ready → 插入正文或封面。

签名包含文件类型、准确长度和 `If-None-Match: *`，避免覆盖对象。接口仍要求已验证的管理员身份与同源请求。

## 本轮真实验证

| 检查 | 结果 |
| --- | --- |
| R2 配置指向独立 blog 桶、blob 前缀、新公共地址 | 通过 |
| 正式域名、localhost:3000 的 PUT 预检 | 204，origin、Content-Type、If-None-Match 均允许 |
