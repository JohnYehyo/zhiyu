# 写一页芝语手账

## 分类

编辑器上方可选择已有分类，也可在“分类名称”输入新名称。新分类随文章保存，随后其他文章可选择使用。它来自当前管理员的文章，不需要再到 Supabase 单独维护分类表。

## 封面

展开“摘要、地址与封面”，点“原型插画”即可选择野餐、草地、鲜花、海边、窗边、阳光六张原型素材。也可上传自己的封面或选择已上传图片。原型素材随网站部署，不依赖 R2 上传。

## 正文排版

- “日记模板”插入小标题、正文、色块、双照片、结尾；有正文时追加到末尾，不覆盖原文。
- “一句话色块”插入独立色块。直接改里面的文字，点击色块后选择六种配色、填写落款。按两次回车回到普通段落。
- “双照片”插入两张原型图片占位。点击照片，点“替换照片”上传自己的照片，或“从素材替换”复用已上传图片；图注、日期、排版会保留。
- 所有正文照片默认白边、胶带的拍立得样式。选中照片可写图注和日期；连续两张都设为“与相邻照片并排”会组成一组，手机自动上下排列。
- 上传替换期间若修改正文，系统停止替换，避免误改其他照片；已确认上传的文件仍保留在素材库，可重新选择。

“预览”使用与公开文章相同的正文渲染。保存草稿不会改变公开文章；点击发布才更新读者看到的版本。

## 本轮部署要求

现有数据库执行一次 [query-journal.sql](../supabase/setup/query-journal.sql)，允许六张内置插画参与发布，并保留色块/照片元数据。它不会重新建表或删除文章；旧的初始化脚本不要重复执行。新项目初始化后也需要该升级。

R2 变量必须配置在实际运行的 Vercel 环境，并重新构建部署。本地 .env.local 不会随 Git 上传。若存储配置缺失，新版只显示缺少或无效的字段名，不显示密钥。图片、封面和视频使用同一条上传链路。
